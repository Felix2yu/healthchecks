Prometheus

{{ site_name }} 为每个项目提供一个 兼容 Prometheus 的指标端点。 这些端点使用每个项目的只读 API 密钥进行保护。 如果您的团队使用 Prometheus，您可以配置它来抓取 {{ site_name }} 的数据，并在 Prometheus 中获取最新的检查项和标签状态值。

设置指南

在 项目设置 › API 访问 中 创建一个只读 API 密钥。

注意：请确保使用只读 API 密钥。 Prometheus 不需要读写 API 访问权限。

编辑 Prometheus 配置，在 scrape_configs 部分添加新配置。 

- job_name: 'healthchecks-{{ project|slugify }}'
  scheme: {{ site_scheme }}
  metrics_path: /projects/{{ project.code }}/metrics/你的只读 API 密钥
  static_configs:
  - targets: ['{% site_hostname %}']

Grafana Cloud 用户注意事项： Grafana Cloud 要求指标端点使用 HTTP "Basic" 或 "Bearer" 认证方案进行身份验证。 它拒绝抓取公共端点。为了满足此要求， {% site_name %} 提供了一个需要 "Bearer" 认证的 替代指标端点。在 Grafana Cloud 中使用以下设置：

  • 抓取任务链接：{{ project.auth_metrics_url }}
  • 认证类型：Bearer
  • Bearer 令牌：只读 API 密钥

重新加载 Prometheus 配置。您现在应该开始看到 {{ site_name }} 的数据出现在 Prometheus 中。
