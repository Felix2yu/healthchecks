Matrix

如果您的团队使用 Matrix， 您可以设置 {{ site_name }} 将通知发布到指定的 Matrix 房间。

设置指南

将 {{ matrix_user_id }} 邀请到您的 Matrix 房间。

注意：加入房间后， {{ matrix_user_id }} 将能够读取房间消息。 请勿邀请到包含敏感内容的房间。 建议创建一个专门用于通知的房间。

进入房间设置 › 通用界面 并查找房间的已发布地址。

如果房间没有已发布地址， 请从房间设置 › 高级界面 查找其内部房间 ID。

在下方表单中输入已发布地址或内部房间 ID， 然后保存集成。

{{ matrix_user_id }} 将很快加入您的房间。之后， 就全部完成了！从现在起，{{ site_name }} 将在检查项 宕机或恢复时向您的房间发布通知。
