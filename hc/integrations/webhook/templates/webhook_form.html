  • HTTP 响应状态码不是 200、201、202 或 204。

支持的占位符

你可以在 Webhook 链接、请求正文和头部值中使用以下占位符。 {% site_name %} 会将占位符替换为正确的值。

$CODE 检查项的 UUID 代码。
$NAME 检查项的名称。
$NAME_JSON

检查项的名称，编码为 JSON 字符串。如果 检查项名称包含双引号，使用以下方式会产生无效的 JSON：

{"name": "$NAME"}

但以下方式可以正常工作：

{"name": $NAME_JSON}
$SLUG 检查项的别名。
$NOW 当前 UTC 时间，ISO8601 格式。示例： "{% now_isoformat %}"
$STATUS 检查项的当前状态（"up" 或 "down"）。
$TAGS 检查项的标签，以空格分隔。
$TAG1, $TAG2, … 第一个标签、第二个标签……的值。
$BODY 最近一次 Ping 的请求正文。仅在 Webhook 的"请求正文"字段中有效。
$BODY_JSON 与 $BODY 相同，但编码为 JSON 字符串。
$EXITSTATUS 最近一次 Ping 的退出状态值。默认值："-1"。
$JSON

检查项的 JSON 表示。 JSON 文档包含与 获取单个检查项 API 响应相同的字段。你可以在自己的 JSON 结构中嵌套 $JSON，示例：

{"now": "$NOW", "check": $JSON}

生成的有效负载将为：

{"now": "{% now_isoformat %}", "check": {"name": "Foo", "slug": "foo", ... }}
