Opsgenie

Opsgenie 提供 警报、值班排班、升级策略和事件跟踪功能。 您只需几个简单步骤即可将其集成到您的 {{ site_name }} 帐户中。

设置指南

登录您的 Opsgenie 帐户， 选择一个团队，进入该团队的 集成页面，点击 添加集成。

在提供的集成类型网格中选择 API。
为集成起一个描述性的名称。

复制显示的 API 密钥，然后点击 开启集成。

将 API 密钥粘贴到下面的表单中，并确保选择了正确的 服务区域。 保存集成，大功告成！
