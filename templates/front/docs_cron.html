Cron 表达式语法速查表

{{ site_name }} 支持大多数传统 cron 语法功能。 底层使用 cronsim 包 来解析和解释 cron 表达式。以下是所支持语法功能的展示。

专业提示！ 在类 Unix 操作系统上，您还可以通过在 shell 中输入 man 5 crontab 来轻松访问 cron 语法文档。

时区

Cron 守护进程使用服务器的本地时间。 如果服务器的时区不是 UTC，请确保在 {{ site_name }} 上也设置匹配的时区。

在 Ubuntu 系统上，您可以使用以下命令检查服务器的时区：

cat /etc/timezone
